Vertical spacing:
	Use \vskip for manual vertical spacing. For example, \vskip 1cm or \vskip 10pt.
	If you want to ensure a page break before a song, use \break or \vfill\break.
	If you want to prevent a page break between two songs, you can use \nobreak\vskip... or group the songs in a \vbox (advanced).
	For flexible spacing, you can use glue: \vskip 1cm plus 0.5cm minus 0.2cm.

	Yeah so none of that shit works thanks to the double page balancing act. BUT there's other much more annoying ways to do what we need. To go in the positive direction add a bunch of "M: ()" at the end of the song file - they're invisible, but still take up vertical space. To go in the negative direction, re-define the spacing macros locally, i.e.:
	{
	  \def\InterSongSkip{1pt}
	  \def\ParSkip{1pt}
	  \inputsong{songs/187_Trh_ve_Scarborough.sng}
	}
	But usually it seems to me to work better to add those invisible verses wherever it can help, you can also just add a line with an empty chord to an existing verse, etc.

Watchout for:
	Literals:
		špatnej apostrof - ´ a ′, má být '
		literal ellipses - …
		hvězdičky - *
		m-dashes a dvojpomlčky - ---/--
		špatně omezeřená čárka -  , 

	REGEX:
		Akordy na konci řádků, kterým nepředchází mezera.
		[^\s]\([^)]+\)$

		Špatnej znak za čárkou:
		,(?![ \}\(\t\r\n])

		special chars in header
		^(?:N|A|AC|Z|ZC):.*[^a-zA-Z0-9 áÁčČďĎéÉěĚíÍňŇóÓřŘšŠťŤúÚůŮýÝžŽ,\r\n].*\R
		^(?:N|A):.*[^a-zA-Z0-9 áÁčČďĎéÉěĚíÍňŇóÓřŘšŠťŤúÚůŮýÝžŽ,\r\n].*\R

		faily v malych akordech, jakože (c) místo (C):
		\([a-z]

		spatne oznaceny sloky jakoze 1. misto 1:
		^\d+\.

		rozbity repetice:
		(?:/:(?! )|(?<! ):/)

		Autoři s "a":
		^A:.* a 

		Prázdný autor:
		^A:[ \t]*$

		broken ellipses (...):
		(?<!\.)\.\.(?!\.)
		\.{4,}

		Vícenásobný reptice co mají x místo ×:
		\b\d+x\b

		Double meaning regex:
		can be used to find broken equality verses where two were on consecutive lines like:
		5: = 1.
		6: = 2.
		But also finds one of the continuation patterns like:
		3: = 1.
		...labutě, labutě.
		This is it:
		^[a-zA-Z0-9]{1,2}: = [a-zA-Z0-9]{1,2}\.\R(?!\R).+

		Náhrada "sus" akordů (Esus4 -> E4):
		\(([A-G][^)]*?)sus([^)]*)\)
		replace with:
		\((\1\2)\)
